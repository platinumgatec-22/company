## 1. طبيعة العلاقة
1. يقدّم المتطوع وقته وجهده **اختيارياً ودون أجر**، دعماً لفعالية [ ] في الفترة من [ ] إلى [ ].
2. لا تُنشئ هذه الاتفاقية علاقة عمل أو شراكة أو وكالة، ولا تُرتّب للمتطوع أجراً أو مكافأة نهاية خدمة.
3. يجوز لأي طرف إنهاء المشاركة في أي وقت، مع إشعار المنظِّم مبكراً قدر الإمكان.

## 2. الدور والمهام
- الدور: [تنظيم الدخول / دعم التسجيل / نقاط الماء / الإرشاد / الإعلام…]
- المواقع والنوبات المقترحة: [ ]، بحد أقصى [6] ساعات للنوبة الواحدة، مع استراحات وماء وظل.
- لا يُكلَّف المتطوع بمهام خطرة أو مهام تتطلب ترخيصاً مهنياً (إسعاف طبي، أمن، قيادة مركبات) إلا إذا كان مرخّصاً لها ومؤمَّناً عليه.

## 3. ما يقدّمه المنظِّم
1. تدريب تمهيدي وإرشادات السلامة وخطة الطوارئ.
2. زي وبطاقة تعريف، ووجبات ومياه أثناء النوبات.
3. **تغطية تأمينية ضد الحوادث الشخصية** أثناء النوبات، بمبلغ [ ] د.ك.
4. **رد المصروفات الفعلية الموثّقة والمعتمدة مسبقاً** (مثل المواصلات)، وهو ليس أجراً.
5. شهادة تطوع بعدد الساعات، وخطاب توصية عند الطلب.

## 4. التزامات المتطوع
1. الالتزام بالمواعيد وبتعليمات المشرف وقواعد السلامة.
2. حسن التعامل مع المشاركين والجمهور، وعدم قبول أي مقابل أو هدايا منهم.
3. عدم التصريح لوسائل الإعلام أو النشر نيابةً عن المنظِّم دون إذن.
4. الإبلاغ الفوري عن أي حادث أو خطر.
5. إعادة الأدوات والعُهد عند انتهاء المشاركة.

## 5. السرية والبيانات
1. يلتزم المتطوع بسرية بيانات المشاركين التي يطّلع عليها، فلا يصوّرها ولا ينسخها ولا يستخدمها لأي غرض آخر، ويستمر هذا الالتزام بعد انتهاء الفعالية.
2. يستخدم المنظِّم بيانات المتطوع لأغراض التنظيم والتأمين والتواصل فقط.
